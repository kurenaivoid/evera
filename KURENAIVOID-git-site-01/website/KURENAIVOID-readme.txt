EVERA サイト（草案）の使い方（第4版）

■ 場所
index.html ........ トップページ（ここから開く）
js/KURENAIVOID-site-data.js ... ★データ（作品・曲・MV・リンク・ストーリー本文・自己紹介）を、ここ1か所にまとめました
player/ ........... ディスクプレーヤー
story/ ............ ストーリー（10本）
play/dj/ .......... DJ（ベータ版）

■ 書き換える場所（すべて js/KURENAIVOID-site-data.js）
  releases … 作品の一覧と公開日（date が今日より先なら COMING SOON）。track は押したときに流す曲の番号
  tracks   … 曲の一覧は、assets/data/KURENAIVOID-tracks.js に移りました（サイトと音ゲーで共通）。ここには、曲ごとの絵（label・art）だけを書きます
  mvs      … MV。youtube に YouTube の動画ID を入れると表示されます
  links    … リンク。u に URL を入れると押せるようになります
  stories  … ストーリーの題名・あらすじ・本文・場面の絵
  people / world … 自己紹介の文章
  lullaby  … 子守唄の歌詞と時間（[始まり秒, 終わり秒, 歌詞]。歌詞のない間は ♪ だけ出ます）
index.html の「（ここに…を入れます）」の部分が、キャッチコピーとプロフィールの仮の文です。

■ 注意
パソコンで直接 index.html を開くと、プレーヤーの逆向きの音と低音は働きません。GitHub などに置くと働きます。

■ 第3版で変わったところ
・音が切れなくなりました：ストーリーとDJは、ページを移らず、サイトの上に重ねて開きます
・画面の下にミニプレーヤー（曲名・再生/停止・前後の曲）を置きました
・DJを開いている間と、ストーリーで子守唄が鳴っている間は、プレーヤーを一時停止します。とじると続きから再開します
・開き直したとき、最後に聴いていた曲と位置を覚えていて、そこで待機します（再生ボタンで続きから）
・PROFILE：パネルが最初から見えていた不具合を直しました。自己紹介の動画は1回だけ流れて、最後の絵で止まります
・ストーリーの絵：4章のカード、9章（路地の場面に3枚）、番外編3（ニナが店の隅に座る場面）を追加・変更しました

■ 第4版で変わったところ
・子守唄の歌詞を、AviUtlのEXOの歌詞と時間に入れかえました（日本語・ロシア語）。1行ずつ、歌い出しに合わせて出ます
・ロシア語の歌詞の前に出ていた数字（[15.0:] など）をなくしました
・プレーヤーが画面の外にあっても、再生・一時停止・次の曲が、ちゃんと効くようにしました（曲が止まる・少し戻る不具合の直し）

■ 第5版で変わったところ（Gitに置く形に変えました）
・曲のmp3と曲の名簿は、サイト（website/）の外、リポジトリのいちばん上の assets/ に置きます
    assets/music/album01/ … 曲のmp3（公開してよい曲だけ）
    assets/data/KURENAIVOID-tracks.js … 曲の名簿（サイトと音ゲーで共通）
・新しい曲は、「mp3を置く」→「名簿に1行足す」の2つだけです。サイトにも音ゲーにも自動で出ます
・子守唄のmp3（assets/music/lullaby/）は、公開するか迷っているため、この版には入れていません
